# Shell, Processes and Signals

This directory contains Bash scripts for process monitoring, signals, PID handling, and process management.

## Mandatory Requirements
* All files executed on Ubuntu 20.04 LTS
* All scripts tested with ShellCheck
* All files made executable (`chmod +x`)

## Task Summary
* `0-what-is-my-pid`: Displays the Process ID (PID) of the executing script.
